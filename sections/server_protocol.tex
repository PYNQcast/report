\subsection{Wire Protocol}
\label{sec:protocol}

All packets are custom fixed-size \texttt{struct}-packed datagrams with no variable-length fields on the hot path. For example, the 24-byte \texttt{NodePacket} (\texttt{<HHIfffB3x>}, Table~\ref{tab:nodepacket}) is transmitted once per tick, little-endian native on both ARM Cortex-A9 and x86-64. Aside from other packets, the server broadcasts a 68\,B \texttt{PKT\_GAME\_STATE}  each tick, and a 1032\,B \texttt{PKT\_MAP} once at match start to program the FPGA BRAM.
