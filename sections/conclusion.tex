\section{Conclusion}
PYNQcast demonstrates a complete IoT gaming platform meeting all 
minimum functional requirements: local FPGA processing, cloud server 
deployment, bidirectional node-server communication, and verified 
multi-node operation. Key contributions include a fully pipelined 
hardware DDA raycaster operating at under $10\%$ capacity at 60fps and 
a SEDA-inspired server sustaining $<$4\,ms overhead under full load. 
Future work includes inline overlay integration and extension to 
additional node types.
