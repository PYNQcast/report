\section{Conclusion}

This project demonstrates that a \$200 FPGA development board can drive a networked multiplayer 3D game when paired with a well-structured cloud backend.  The separation of concerns---FPGA renders, ARM networks, EC2 validates---enabled parallel development and clean performance isolation.  Future work includes scaling to four players, implementing the PMOD peer-to-peer link for hardware-demo purposes, and deploying the Parquet/Athena analytics pipeline.
