\section{Networking \& Persistence}

\subsection{Protocol}

All game traffic uses UDP with a lightweight custom header (8\,B).  The server applies authoritative validation before broadcasting deltas at the tick rate.

\begin{designnote}[Latency note]
Client-side prediction on the PYNQ ARM masks up to 2 ticks ($\leq$100\,ms) of round-trip latency, interpolating between confirmed server states.
\end{designnote}

\subsection{Three-Tier Storage}

Post-game data flows through the persistence tiers shown in Figure~\ref{fig:arch}.  An async Python sidecar decouples AWS SDK latency from the real-time C++ loop:

\begin{lstlisting}[language=Python, caption={Sidecar write-behind batch flush.}]
async def flush_batch(batch, table):
    async with table.batch_writer() as w:
        for item in batch:
            await w.put_item(Item=item)
    metrics.incr("ddb.flush", len(batch))
\end{lstlisting}
